# Commits

`CONTRIBUTING.md` at the repository root is the sole source of truth for branch names, commit
partitioning, staging discipline, Gitmoji commit message format, validation, history safety and the
commit review checklist.

- Read `CONTRIBUTING.md` before creating or approving a commit, and apply it exactly.
- Do not restate, summarise or reinterpret its rules here or anywhere else. A second copy becomes a
  competing source of truth and drifts.
- The `aubaine-commit` skill defers to the same file.
- Apply it only when a commit is explicitly requested.
