# Review Before Completion

- Re-read the task after implementation and verify every requested behavior is represented in the diff.
- Review changed files as a coherent system, not only file by file.
- Check for duplicated logic introduced by the change.
- Check runtime boundaries and hydration boundaries.
- Check keyboard and reduced motion behavior for interactive UI.
- Check localized routes, canonical URLs, alternate locale links, and document language when relevant.
- Check Swup full load and client navigation behavior when relevant.
- Check that authored content remains factual, sourced where required, and free of production process language.
- Check that no authored source comments were introduced.
- Check that U+2013 and U+2014 were not introduced in authored text.
